The LEO Context Data Platform

From Experience to New Experience

LEO turns customer experience into a continuous learning system. Customer 360 data becomes context, context becomes decisions, and every outcome improves the next experience.

Concept What LEO understands State example
01

Experience

Collect the evidence of what happened across Customer 360, events, transactions, conversations, CRM, and social touchpoints.

{ "event": "cart_abandoned", "channel": "web", "value": 89 }
02

Learned Model

Convert accumulated evidence into useful predictions: value, churn risk, lead score, segments, behavioral patterns, and trends.

{ "churnRisk": 0.72, "segment": "high_intent", "ltv": 1240 }
03

Kernel / Lens

Use the Dynamic Persona as the customer lens that connects interests, intent, values, needs, state, and confidence.

{ "intent": "compare_plans", "need": "clarity", "confidence": 0.88 }
04

Perception

Read the customer’s present situation from real-time signals, active channel, environment, lifecycle stage, and immediate needs.

{ "channel": "email", "stage": "trial", "signal": "pricing_page" }
05

Interpretation

Apply decision intelligence to explain what the context means, weigh business goals, and keep the decision within guardrails.

{ "insight": "needs_plan_guidance", "goal": "conversion", "policy": "approved" }
06

Action

Deliver the next best action through personalization, campaigns, recommendations, AI agents, or workflow automation.

{ "nextBestAction": "send_plan_comparison", "owner": "campaign_ai" }
07

New Experience

Capture the response, conversion, feedback, satisfaction, retention, and new behavior created by the action.

{ "response": "clicked", "converted": true, "feedback": "helpful" }

Dynamic Persona 360

The most important connecting layer: it carries a continuously updated customer understanding through all seven steps, so every interpretation and action remains personal, contextual, and explainable.

{ "personaId": "p_1024", "state": "evaluating", "intent": "upgrade", "nextBestAction": "advisor_chat" }

Make Every Customer Signal Useful

Experience → Learned Model → Dynamic Persona → Perception → Interpretation → Action → New Experience

  2. 02Learned ModelWhat have we learned?
  3. 03Kernel / LensHow do we see?
  4. 04PerceptionWhat is happening now?
  5. 05InterpretationWhat does it mean?

  7. 07New ExperienceWhat happened next?
